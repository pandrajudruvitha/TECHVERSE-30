# Module Catalog

This catalog separates modules and subindustries into catalogable domains. Statuses
describe the actual repository, not the future vision.

## Status Legend

- **Implemented**: runnable application behavior exists
- **Tested**: covered by automated validation
- **Simulated**: local synthetic or browser-local behavior
- **Integration Required**: implemented but needs external configuration or service
- **Planned**: designed in this roadmap but not implemented
- **Blocked**: cannot proceed until a dependency is resolved
- **Not Started**: no implementation exists

### Industry 20 - Future Technologies and Frontier Innovation

Status: **Implemented**

Create one catalog universe covering emerging, experimental, commercial,
theoretical, and speculative innovation. Each entry must classify maturity:

- Commercially available
- Active research
- Experimental prototype
- Theoretical concept
- Fictional or speculative simulation

Fictional or speculative capabilities must never be presented as real products or
functional technologies.

All 20 industry categories have routed landing/workspace pages and maturity-labelled
frontier guidance. Dedicated industry-specific tool implementations remain incremental
under the shared workspace.
